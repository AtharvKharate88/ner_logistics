## ML Module Structure

This module is organized by work stage:

- `src/terrain/` for DEM and road-terrain processing
- `src/rainfall/` for rainfall data extraction and feature building
- `src/model/` for training, evaluation, preprocessing, and prediction utilities
- `data/raw/` for source datasets
- `data/processed/` for generated CSV outputs
- `models/` for saved model artifacts
- `notebooks/` for exploratory work
